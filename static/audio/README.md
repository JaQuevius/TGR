# Soundbite Audio Clips Directory

Place royalty-free audio clips or original recordings here (WAV, MP3, or OGG format).

## Audio Guidelines
1. **Format**: WAV or MP3, preferably 44.1 kHz, normalized volume.
2. **Duration**: 8 to 12 seconds per clip.
3. **Naming**: Name files using their track id (e.g. `bread-1.wav`, `jazz-intro.mp3`).
4. **Licensing**: Only use royalty-free music, Creative Commons Zero (CC0) audio, or original studio recordings. Never use copyrighted commercial tracks without proper rights.

The server automatically streams any files placed here via `/audio/<id>` with HTTP 206 Partial Content support for iOS Safari.
